Blog Web - Proyecto Final Django

Descripción

Aplicación web de un blog desarrollada con Python y Django. Permite a los usuarios registrarse, iniciar sesión y gestionar publicaciones.

Funcionalidades

Registro de usuarios.

Inicio y cierre de sesión.

Creación de publicaciones.

Visualización de publicaciones y detalles.

Edición de publicaciones propias.

Eliminación de publicaciones propias.

Carga y visualización de imágenes.

Control de permisos mediante autenticación.

Tecnologías utilizadas

Python

Django

HTML

CSS

SQLite

Git y GitHub
